# Level 0 — превью генерации

Интерактивная карта Level 0 сверху с ползунками. Работает локально из файла,
ничего собирать не нужно.

## Открыть

Двойной клик по `index.html` или:

```sh
xdg-open tools/level0-preview/index.html
```

## Что видно на карте

- жёлтое — вырезанное пространство (коридоры, двери, комнаты);
- тёмное — сплошная масса стен;
- красноватые пиксели — вырезано, но недостижимо из точки входа;
- коричневая клетка — шкаф (клетка непроходима), светлая — остальная мебель
  (для статистики считается проходимой);
- голубой крестик — точка входа `/backrooms enter`;
- красный крест — запертая комната (её центр недостижим).

Серые чипы под картой: процент вырезанного, достижимость от спавна, число
запертых комнат, число комнат в кадре, количество мебели по типам, диапазон
высот пола.

Галочка **«Показать свет»** в блоке «Вид» рисует поверх карты сетку ламп:
жёлтая точка — светящаяся панель, серая — перегоревшая лампа, затемнённые
квадраты — тёмные районы, где панелей нет вообще.

## Как применить настройки

1. Покрути ползунки, посмотри на карту.
2. Нажми **«Скачать config.json»** — файл `level0-config.json` сохранится
   (обычно в `~/Downloads`).
3. Скажи в чате, что конфиг готов.

Значения из JSON переносятся в константы `Level0Plan.java` (ключи совпадают
1:1), затем мод пересобирается. После этого новые значения становятся
дефолтом в игре.

Кнопка **«Скопировать JSON»** кладёт тот же конфиг в буфер обмена, а
**«Показать JSON»** — в текстовое поле.

## Точность модели

`core.js` — порт `Level0Plan.java`: тот же 64-битный хеш, те же соли и те же
формулы. `DEFAULT_CONFIG` совпадает с константами игры.

Превью показывает план сверху. Геометрия — офисная: нерегулярная сетка
улиц-коридоров, между ними блоки. Улица сдвигается на каждом сегменте
(`wander`), поэтому длинных идеально прямых коридоров нет. Стенка блока
может быть открыта прямо в коридор (`wallOpen`) или утолщена (`wallThick`).
Если сегмент улицы не существует, на его месте иногда вырезается зал
(`hallChance`), который соединяет два соседних блока без коридора. Блок
застраивается одним из четырёх типов: открытый зал с колоннами, кабинеты
вокруг внутреннего коридора, сьют с подсобкой или две комнаты с широким
проёмом. В кабинетах есть короткие перегородки. Иногда в глухой стене
прорезается фальш-дверь (`falseDoorChance`) — за ней карман-тупик, а не
проход. Редкий район 2×2 целиком может стать плазой (`plazaChance`): один
пустой зал с редкой сеткой колонн, без внутренних улиц.

Внутри комнат из того же хеша расставляется мебель. Шкафы, стеллажи и
мелкие предметы (растение, кулер, урна, принтер) стоят у внутренней стены:
не ближе двух клеток к дверям, не на лестницах и не рядом с ними, клетка
перед мебелью остаётся свободной. Стол стоит на открытом полу, а перед ним
ставится стул лицом к столу. У столов три варианта дерева, у стульев,
шкафов, стеллажей и растений — два; `facing` задаёт сторону, куда смотрит
передняя сторона модели. Позиции считаются по соли
`SALT_FURNITURE = 0x0F1E2D3C4B5A6978`, варианты — по
`SALT_FURNITURE_VARIANT`, поворот и шанс стула — по
`SALT_FURNITURE_FACING`; все три общие у Java и `core.js`.

В превью только шкаф помечает клетку непроходимой, остальная мебель
считается проходимой — так статистика связности не зависит от коллизий
отдельных моделей.

В редких больших залах с высоким потолком (`furniturePileChance`) в центре
комнаты появляется гора мебели: девять предметов на полу 3×3, два на втором
слое и один сверху. Если центр занят колонной, дверью, лестницей или уже
расставленной мебелью, гора не ставится. Минимальная сторона зала —
`furniturePileMinRoom`. Блок точки входа исключён. В превью клетки горы
рисуются как обычная мебель и считаются проходимыми.

Полы строго горизонтальны. Каждый блок (и все его комнаты) стоит на одном
уровне; районы 2×2 блока иногда приподняты или опущены на 3 блока. Районы
другого уровня подкрашены светлее/темнее, а входы в них — оранжевые
лестницы по 3 ступени из ковра у дверей. Внутри площадок и коридоров ступеней нет.
Блоки одного района соединены залами на высоте района: их внутренние улицы
не режутся, а на месте пропавшей границы вырезается мост. Если у блока
другого уровня обе внешние границы оказались глухими, одна из них
принудительно открывается, чтобы блок не остался без входа и не выпал из
плана. Часть залов получает высокий потолок (`hallCeilMax`); колонны и
внутренние двери такого зала вырезаются до нового потолка.

Свет — не идеальная решётка: целые квадраты 48×48 могут быть тёмными
(`darkChance`), а отдельные панели на сетке 12×12 перегорают
(`deadLightChance`). Тёмные квадраты кратны сетке ламп, поэтому граница
района не рвёт шаг панелей. Панель светит на 8, поэтому даже под ней сумрак,
а между панелями — темнота.

Проверка связности повторяет правила игры: подъём не больше 0.5 блока за шаг
(ступенька прячет два полушага в одной клетке), спуск — любой. Статистика
считается по внутреннему окну с отступом 48 блоков от края кадра, потому что
край кадра обрезает мир и не является стеной.

| `wander`          | `WANDER`            |
| `streetWidthMax`  | `STREET_WIDTH_MAX`  |
| `segmentChance`   | `SEGMENT_CHANCE`    |
| `blockChance`     | `BLOCK_CHANCE`      |
| `wallOpen`        | `WALL_OPEN`         |
| `wallThick`       | `WALL_THICK`        |
| `hallChance`      | `HALL_CHANCE`       |
| `falseDoorChance` | `FALSE_DOOR_CHANCE` |
| `doorWidth`       | `DOOR_WIDTH`        |
| `wideOpening`     | `WIDE_OPENING`      |
| `columnSpacing`   | `COLUMN_SPACING`    |
| `partitionChance` | `PARTITION_CHANCE`  |
| `furnitureCabinetChance` | `FURNITURE_CABINET_CHANCE` |
| `furnitureCabinetMax`    | `FURNITURE_CABINET_MAX`    |
| `furnitureDeskChance`    | `FURNITURE_DESK_CHANCE`    |
