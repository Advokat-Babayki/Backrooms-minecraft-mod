# Backrooms

Неофициальный мод для Minecraft на NeoForge, который добавляет Backrooms Level 0
как настоящее измерение: бесконечные жёлтые офисные коридоры, влажный ковёр и
непрекращающийся гул лампы.

Версия 0.1.0 · Minecraft 1.21.1 · NeoForge 21.1.267+ · Java 21

## Что внутри

- измерение `backrooms:level0` с собственным генератором;
- шесть блоков и предмет «Миндальная вода» в отдельной вкладке креатива;
- 60-секундная бесшовная петля гула, привязанная к биому;
- команды для входа, выхода и определения места.

| Блок | Что это |
|---|---|
| `yellow_wallpaper` | жёлтые обои: стены и сплошная масса уровня |
| `moist_carpet` | влажный ковёр: пол |
| `ceiling_tile` | потолочная плитка |
| `fluorescent_panel` | флуоресцентная лампа, свет 15 |
| `wallpaper_slab` | обойная плита: лестницы и перепады высоты |
| `red_wallpaper` | красные обои, декоративные вставки |

Все блоки неразрушимые (`strength(-1, 3600000)`), как и положено стенам уровня.

## Как попасть

| Команда | Действие |
|---|---|
| `/backrooms enter` | телепортирует в Level 0 и запоминает точку возврата |
| `/backrooms leave` | возвращает в точку входа |
| `/backrooms room` | печатает блок, тип застройки, комнату и уровень пола |

`room` пригодится при отладке генерации: она называет конкретное место, где ты
стоишь.

Точка возврата хранится в памяти сервера. После перезапуска `leave` уже не знает,
куда возвращать, — выходить придётся телепортом.

## Генерация Level 0

Уровень строится не из комнат, а наоборот: сначала весь чанк (y=60..105)
заполняется обоями, затем из монолита вырезаются улицы, комнаты, двери и
лестницы. Поэтому стены, потолки и перегородки срастаются сами, а игрок
физически не может выбраться на крышу.

- Улицы — прямые коридоры с шагом 64 ± 20 блоков и шириной 3–7 блоков; 65%
  сегментов между перекрёстками существуют.
- Между улицами — кварталы: открытый зал с колоннами, кабинеты вокруг
  внутреннего коридора, сьют с подсобкой или две комнаты с широким проёмом.
- Полы горизонтальные. Кварталы объединены в районы 2×2; целый район иногда
  приподнят или опущен на 3 блока, а у дверей на улицу стоят лестницы из
  6 полушагов.
- Потолок в 4–5 блоках над полом, лампы сеткой каждые 6 блоков.
- Вход — центр первой комнаты принудительного квартала около (0, 0).

План — чистая функция от seed и координат: соседние чанки всегда сходятся на
границах. Посмотреть его сверху и покрутить параметры можно в
[`tools/level0-preview/`](tools/level0-preview/README.md) — там же описано, как
переносить значения в `Level0Plan.java`.

## Установка

Нужны Minecraft 1.21.1, NeoForge 21.1.267 или новее и Java 21.

1. Собери `backrooms-0.1.0.jar` (см. ниже) или скачай готовый из релизов.
2. Положи его в папку `mods/`.
3. Запусти игру и введи `/backrooms enter`.

## Сборка

```sh
./gradlew build
# готовый мод: build/libs/backrooms-0.1.0.jar

./gradlew runClient   # клиент с модом
./gradlew runServer   # сервер
./gradlew runData     # датаген
```

Первая сборка скачивает NeoForge и Parchment mappings, нужен интернет.

## Инструменты разработчика

| Файл | Что делает |
|---|---|
| `tools/level0-preview/` | HTML-карта Level 0 сверху с ползунками. Экспортирует `level0-config.json`, значения из которого переносятся в константы `Level0Plan.java` |
| `gen_hum.py` | синтезирует `hum.ogg`: 60 секунд, моно, бесшовная петля. Нужны Python 3 и ffmpeg |
| `gen_textures.py` | рисует 16×16 текстуры блоков и миндальной воды, только стандартная библиотека Python. Рядом кладёт `build/texture_preview/`: тайлинг 3×3 и симуляцию мипмапа |

```sh
xdg-open tools/level0-preview/index.html
python3 gen_hum.py
python3 gen_textures.py
```

```text
  Level0Generator.java     переносит план в блоки чанка
  BackroomsWorldgen.java   регистрация кодека генератора

  BackroomsBlocks.java     блоки и предметы
  BackroomsSounds.java     звуковое событие hum
  BackroomsModClient.java  клиентская инициализация
src/main/resources/

  assets/backrooms/        блокстейты, модели, текстуры, звук, lang
tools/level0-preview/      офлайн-превью генерации
```

## Статус

0.1.0, только Level 0. Других уровней, естественного спавна мобов, лута и
структур пока нет. Генератор рассчитан на высоту измерения 128, ванильные
высоты ему не подходят.
